# ADR-003: Argon2id for Password Hashing

**Status:** ACCEPTED

## Context
Password storage requires a memory-hard, ASIC-resistant algorithm to resist offline brute-force attacks.

## Decision
Use Argon2id (the data-dependent variant of Argon2) with configurable memory cost, time cost, and parallelism parameters via environment variables.

## Consequences
+ Industry-standard password hashing (winner of PHC)
+ Configurable work factors via env vars (ARGON2_MEMORY_COST, ARGON2_TIME_COST, ARGON2_PARALLELISM)
+ Memory-hard — resistant to GPU/ASIC attacks
- CPU intensive on the server (intentional)
- Legacy systems may not have Argon2 libraries available

## Evidence
- `backend/src/config/env.ts`: ARGON2_MEMORY_COST=65536, ARGON2_TIME_COST=3, ARGON2_PARALLELISM=2
- `backend/src/modules/auth/auth.service.ts`: hashPassword(), verifyPassword() using argon2
