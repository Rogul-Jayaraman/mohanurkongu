# ADR-005: React 19 + Vite SPA with i18next

**Status:** ACCEPTED

## Context
The platform needs a modern, fast, internationalized frontend for Tamil Nadu's Kongu Vellalar community, with Tamil as the primary language and English as secondary.

## Decision
Use React 19 with TypeScript, Vite for build tooling, React Router v6 for routing, and i18next with react-i18next for localization.

## Consequences
+ React 19 provides latest features (concurrent rendering, server components)
+ Vite provides fast HMR and optimized builds
+ i18next provides established i18n with lazy loading, pluralization
+ 16 namespaces for organized translations (common, auth, signup, dashboard, etc.)
- SPA approach requires Nginx for SPA fallback routing
- i18n initialized synchronously — no loading state for language resources

## Evidence
- `frontend/src/main.tsx`: React 19 + I18nextProvider
- `frontend/src/App.tsx`: 65 routes across 6 route groups
- `frontend/src/i18n.ts`: i18next config with en/ta, 16 namespaces
- `frontend/src/locales/`: Translations directory
