# ADR-001: Express 5 with Prisma/PostgreSQL for Backend

**Status:** ACCEPTED

## Context
The platform requires a scalable, well-documented backend framework for a matrimony + mandapam booking system with user auth, profile management, and booking workflows.

## Decision
Use Express 5 with TypeScript as the web framework, Prisma as the ORM, and PostgreSQL 16 as the database.

## Consequences
+ Express 5 is lightweight, well-known, and has a mature middleware ecosystem
+ Prisma provides type-safe database access with auto-generated TypeScript types
+ PostgreSQL provides ACID compliance needed for booking transactions
- Express 5 lacks built-in DI, guards, and module system (unlike NestJS)
- Prisma migrations are unidirectional (no native "down" support)
- Raw SQL needed for complex queries beyond Prisma's capabilities

## Evidence
- `package.json`: `"express": "^5.0.0"`
- `prisma/schema.prisma`: Full database schema
- `backend/src/app.ts`: Express app initialization with middleware chain
