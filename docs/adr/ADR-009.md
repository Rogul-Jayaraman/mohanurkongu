# ADR-009: Device Fingerprinting for Session Tracking

**Status:** ACCEPTED

## Context
The platform needs to track which devices a user is logged in from, for security monitoring and "sessions" display (not yet implemented).

## Decision
Capture device fingerprint on login by hashing IP + User-Agent + Accept-Language + Accept headers with SHA-256. Store fingerprint and individual hashes in the `sessions` table.

## Consequences
+ Minimal data collection — IP and user agent hashed before storage
+ Privacy-preserving — raw IP and UA not stored
+ Fingerprint enables device recognition for security alerts
- Fingerprint changes on network change (IP changes) or browser update (UA changes)
- No location data stored (only IP hash — can't geolocate)
- `deviceName` and `deviceLocation` fields are nullable, not populated

## Evidence
- `backend/src/common/utils/device.ts`: getDeviceInfo() → ipHash, userAgentHash, fingerprint
- `backend/src/modules/auth/auth.service.ts`: login() calls getDeviceInfo()
- `backend/prisma/schema.prisma`: sessions table has ipHash, userAgentHash, fingerprint columns
