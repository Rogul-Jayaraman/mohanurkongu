# ADR-010: Two-Language Support (Tamil + English)

**Status:** ACCEPTED

## Context
The platform serves the Kongu Vellalar community in Tamil Nadu. The primary language is Tamil, with English as secondary for non-Tamil-speaking users.

## Decision
Use i18next with two locales (ta, en) and 16 namespaces. Default language is Tamil (`ta`), persisted in localStorage under key `language`. Templates use `defaultNS: "common"`.

## Consequences
+ Comprehensive — 16 namespaces cover all UI areas (auth, dashboard, admin, maaligai, etc.)
+ Language persists across sessions via localStorage
+ Template rendering via i18next's ICU message format (if configured)
- Admin translations are for stub-only pages — will need updating when real backend implemented
- Some UI areas may have incomplete translations

## Evidence
- `frontend/src/i18n.ts`: Config with 16 namespaces for en and ta
- `frontend/src/locales/`: Translation files
- `frontend/src/context/LanguageContext.tsx`: Language provider
